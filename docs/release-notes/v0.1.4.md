## New
- **Print**: "Print…" in a capture's context menu opens the system print dialog. With several captures selected, "Print N images…" prints one image per page. Annotations are included.

## Fixed
- **Linux packages are back**: v0.1.3 shipped without the `.deb` and `.AppImage`, because an update of the screen capture library did not compile on Linux. The library is pinned to the previous version. On Linux, this release also brings everything new in v0.1.3: the colour picker, pixel-precise selection, Shift in the editor and the keyboard shortcuts summary.
