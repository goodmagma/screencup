## New
- **Automatic updates**: Screencup checks GitHub for a new version at start and every 6 hours, and offers "Update and restart" in the gallery. Manual check in the About window; can be turned off in the settings. Works from this version on: 0.1.0 must be updated by hand once.
- **Crop and resize** in the editor. Both stay reversible: "Remove crop" and the original size are available also after saving and reopening.
- **New editor tools**: freehand pen, magnifier (shows the image beneath at 2×), polygon, callout (speech balloon with text and a movable tail) and curly brace (resizable and rotatable).
- **Save as PNG, JPG or PDF**, from the editor and from the gallery menu.
- **Share panel**: the Share button opens a panel with temporary link, permanent link and **e-mail** (captures attached to a new message in the mail app), plus Settings and the history of shared links.
- **Open with…** in the gallery menu, to pick the app that opens a capture.

## Changed
- New tool order in the editor column.
- One official icon everywhere: the red cup with a white outline now also appears in the Start menu, on the desktop and in the README.
- Sharing settings: the default service is gone (the Share panel asks each time); the lifetime of temporary links stays.

## Install
Download `Screencup_0.2.0_x64-setup.exe` below and run it. No administrator rights needed.

Windows SmartScreen may warn that the app is not recognised, because the installer is not signed yet. Choose "More info", then "Run anyway".
