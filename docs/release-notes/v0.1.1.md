## New
- **Automatic updates**: Screencup checks GitHub for a new version at start and every 6 hours, and offers "Update and restart" in the gallery. There is a manual check in the About window, and the automatic check can be turned off in the settings. Updates work from this version on: 0.1.0 must be updated by hand once.
- **Crop and resize** in the editor. Both stay reversible after saving and reopening ("Remove crop" and the original size are still available).
- **New editor tools**: freehand pen, magnifier (shows the image beneath at 2×), polygon, callout (speech balloon with text and a movable tail) and curly brace (resizable and rotatable).
- **Save as PNG, JPG or PDF**, from the editor and from the gallery menu.
- **Share panel**: the Share button opens a panel with:
  - a temporary link or a permanent link;
  - **e-mail**, with the captures attached to a new message in the mail app;
  - Settings and the history of shared links.
- **Open with…** in the gallery menu, to pick the app that opens a capture.

## Changed
- New tool order in the editor column.
- One official icon everywhere: the red cup with a white outline is now also used in the Start menu, on the desktop and in the README.
- Sharing settings: the default service is gone, because the Share panel asks each time. The lifetime of temporary links stays.
