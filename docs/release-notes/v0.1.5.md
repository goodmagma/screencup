## New
- **Paste images in the editor**: Ctrl+V, or the new "Paste image" button, adds the picture in the clipboard (or the first image file copied in the file manager) on top of the capture. It can be moved, resized (keeping its proportions; Shift frees them), rotated and deleted, and stays editable after saving.
- **Update badge on the tray icon**: when a new version is found, the tray icon gets a blue dot and its tooltip names the version.
- **"Check for updates…" in the tray menu**: opens the About window and starts the check.

## Changed
- **Blur and magnify** also act on pasted images, not only on the original capture.
- **Blur tool icon**: a pixel mosaic instead of a grid.
