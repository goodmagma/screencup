First public release of Screencup: screenshots, annotations and screen recordings from the system tray, for Windows.

## Capture
- Region capture on a frozen screen, with snapping to windows (mouse wheel to step into panels and controls).
- Full-screen capture, or all screens at once.
- New captures copied to the clipboard (optional).

## Gallery
- Opens from the tray icon, anchored to the bottom-right corner of the screen.
- Thumbnails of screenshots and recordings.
- Multi-select with Ctrl/Shift click and Ctrl+A; Delete moves the selection to the trash.
- Drag captures out to other apps (image editors, chats, Explorer).
- Share captures with anonymous links: temporary (Litterbox, 1–72 h) or permanent (Catbox), copied to the clipboard.
- Optional cap on the number of captures: the oldest ones go to the trash.

## Editor
- Arrows, lines, rectangles and ellipses (Alt for a square or circle), highlighter, blur, text and numbered steps.
- Every element stays selectable, movable, resizable, rotatable and deletable, also after saving and reopening (non-destructive edits).
- Copy & close, save, copy the image to the clipboard.

## Screen recording
- Record a region or a full screen to MP4 (H.264).
- Set-up phase: a dashed frame around the area, which can be moved and resized, and a panel with microphone, system audio and click-highlight toggles.
- Microphone and system audio in recordings.
- Optional click highlights in the video.
- Frame and panel never appear in the video.

## Settings and app
- Settings window: library folder, start at login, global hotkeys, frame rate, audio sources, sharing.
- User interface in English, Italian, Spanish, French, German and Portuguese (follows the system language by default).
- About window with version, GitHub link and licences.
- MIT License; third-party licences included in the installer.

## Install
Download `Screencup_0.1.0_x64-setup.exe` below and run it. No administrator rights needed.

Windows SmartScreen may warn that the app is not recognised, because the installer is not signed yet. Choose "More info", then "Run anyway".
