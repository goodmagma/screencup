## New
- **Stacking order of shapes in the editor**: overlapping shapes can now be brought to the front or sent to the back with the new ribbon buttons. Ctrl+Up and Ctrl+Down move the selected shapes one level, and Ctrl+Shift+Up and Ctrl+Shift+Down move them to the front or the back.
- **Right-click menu on shapes**: right-clicking a shape opens a menu with copy, paste, the stacking order actions and delete.
- **Adjustable blur strength**: with the blur tool, the size buttons set how strong the blur is, from light to strong. Picking a size with a blur selected changes it.

## Changed
- **Smooth blur**: the blur tool now blurs the area smoothly instead of turning it into coarse pixel blocks, so text written over it stays readable.
